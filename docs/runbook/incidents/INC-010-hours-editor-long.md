# INC-010: Hours editor is long

| Field | Value |
|---|---|
| Date found | 2026-10-15 |
| Severity | S3 |
| Area | mobile |
| Status | open |
| Original ID | B6 |

## Summary

The hours editor shows 7 large cards, one for each day. An owner with the same hours each day must enter them 7 times.

## Impact

Setup takes longer for business owners. No data is wrong.

## Detection

The Step 1 device check noted it as a UX item. Commit da9edbc recorded it on 2026-10-15.

## Timeline

Unknown.

## Root cause

The editor has no copy action between days.

## Fix

None yet.

## Verification

Not applicable.

## Follow-ups

Add "Copy to weekdays" and "Copy to all" to the hours editor.

None.
